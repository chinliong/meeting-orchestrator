The AI subtask feature breaks a single action item into an ordered checklist. Unlike transcript parsing, this is **open-ended generation with no single correct answer**, so precision and recall cannot be measured. Instead a second model, the judge, scores each checklist from 1 to 5 on four points: relevance, actionability, coverage and non-redundancy.

- Implemented generator: `gemini-3.6-flash` (Gemini Flash)
- Judge: `claude-sonnet-4-6`, held fixed across both generators and both sets
- Test sets: short (12 tasks), long (12 tasks)

## Decision

**Subtask checklists are generated by Gemini Flash.** Out of 5, it scores 4.786 against Claude Sonnet's 4.822 on the short set (p = 0.652), and 4.872 against Claude Sonnet's 4.878 on the long set (p = 1.0). The p-values come from an exact paired permutation test over the per-task scores; a difference is called significant only when p < 0.05. Neither set shows a significant difference in quality, so the choice rests on cost and on keeping the system on one provider: Gemini Flash costs a tenth of Claude Sonnet's price per input token and a sixth per output token.

The two differ in the form of their checklists rather than their quality: on both sets Claude Sonnet writes more subtasks per task (5.36 against 4.74 on the short set; 5.66 against 5.02 on the long set) and scores higher on coverage, while Gemini Flash scores higher on non-redundancy.

The judge, `claude-sonnet-4-6`, is also the Claude generator, so it scored its own output. If that has any effect, it favours Claude, and Claude still does not score significantly higher than Gemini.
